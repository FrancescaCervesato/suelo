Botón segmentado

Grupo de botones mutuamente excluyentes para cambiar vistas o filtros. En Figma existen dos patrones bajo este mismo nombre: un grupo bordeado de selección única, y un grupo con relleno tipo toggle.

Cómo usarlo

Agrupa entre 2 y 6 opciones mutuamente excluyentes en un solo control compacto, para que la persona usuaria compare alternativas y cambie de vista o filtro sin perder el contexto de la pantalla actual.

✓ Hacer
  • Usarlo para alternar entre pocas vistas o filtros estrechamente relacionados (ej. Lista / Grilla / Mapa).
  • Elegir el grupo bordeado para etiquetas de texto más largas.
  • Reservar el grupo con relleno (pastillas, tamaño 24) para opciones cortas y compactas, como códigos de moneda.
  • Mostrar siempre de forma clara cuál opción está activa.
✕ Evitar
  • Usarlo con más de 6 opciones — a partir de ahí, un Select o Tabs comunican mejor.
  • Confundirlo con Tabs: acá el cambio es inmediato sobre el mismo contenido, no una navegación a otra sección.
  • Combinar los dos patrones (bordeado y con relleno) dentro de un mismo grupo.
  • Usarlo para disparar acciones (como "Guardar" o "Cancelar") — es para alternar estados, no para ejecutar comandos.
