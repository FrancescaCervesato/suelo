Qué hacer y qué no

Hacer

Usar el tipo Individual para una fecha única y Rango para períodos (ej. un estado de cuenta).

Marcar siempre visualmente el día actual y el día seleccionado.

Permitir también escribir la fecha en el campo de texto para quienes prefieren tipear.

No hacer

Usarlo para seleccionar solo una hora sin fecha — el selector de hora es un campo aparte.

Forzar el calendario abierto como único método de carga de fecha.

Inventar un estado visual para los días intermedios de un rango — Figma solo documenta Inicio y Fin.
