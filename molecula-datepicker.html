Tip de uso
Usá el tipo Rango para filtros de fechas (ej. estados de cuenta) y el tipo Individual para campos de fecha únicos, como una fecha de nacimiento.
Nota técnica
Documentado en Sistema de diseño 1.0 · Figma, página "Manual de Componentes". Figma no documenta un estado visual propio para los días intermedios de un rango seleccionado (solo Inicio y Fin rango) — no se inventó uno para esta ficha. El ejemplo interactivo de esta ficha es una implementación de referencia para navegar el sistema — no reemplaza al componente productivo de la librería de Figma.
