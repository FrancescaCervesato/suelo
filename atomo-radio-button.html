Radio Button

Control de selección única dentro de un grupo. Estados: default, seleccionado y deshabilitado. Indicado para opciones mutuamente excluyentes.

Cómo usarlo

Obliga a elegir exactamente una opción entre un conjunto pequeño y siempre visible de alternativas mutuamente excluyentes.

✓ Hacer
  • Usarlo cuando todas las opciones deben estar visibles a la vez para poder compararlas.
  • Preseleccionar una opción cuando exista un valor recomendado o más común.
  • Mantener el grupo entre 2 y 4 opciones.
✕ Evitar
  • Usarlo con 5 opciones o más — a esa altura, un Select ordena mejor la información.
  • Dejar el grupo sin ninguna opción marcada cuando el contexto exige un valor.
  • Usarlo si se puede elegir más de una opción — para eso está el Checkbox.
