Empty State

Pantalla vacía cuando no hay contenido disponible. Incluye ilustración, título, subtítulo y hasta dos botones, todos opcionales. Dos tamaños: Default y Chico.

Cómo usarlo

Reemplaza una pantalla o sección vacía por un mensaje que explica por qué no hay contenido y qué acción tomar a continuación, en vez de dejar un espacio en blanco.

✓ Hacer
  • Explicar la causa puntual de la ausencia de datos ("Todavía no cargaste ningún campo").
  • Ofrecer un botón primario que resuelva la causa (ej. "Agregar campo").
  • Usar el tamaño Chico dentro de componentes más pequeños y Default para pantallas completas.
✕ Evitar
  • Reusar el mismo texto genérico para causas distintas ("no hay datos" vs "sin resultados de tu búsqueda").
  • Mostrarlo sin ninguna acción cuando sí existe una forma de resolver el estado vacío.
  • Usarlo para errores del sistema — para eso está el Toast de advertencia.
