Qué hacer y qué no

Hacer

Marcar siempre con el estado Select cuál sección está activa.

Usar Subcategoría para submenús anidados dentro de una sección padre.

Mostrar el tooltip con el nombre completo de cada ítem cuando el sidebar está colapsado.

No hacer

Colapsar el sidebar sin dejar ninguna forma de identificar cada ítem — el tooltip no es opcional en ese estado.

Anidar más de un nivel de Subcategoría.

Usarlo para acciones puntuales de una pantalla — eso corresponde a un botón o menú contextual.

Anatomía

Propiedades documentadas de este componente

PropiedadEstadoValores: Default, Hover, Select — Hover y Select usan el mismo tono celeste con borde; Select es más saturado.
PropiedadTamañoValores: 224px (expandido), 60px (colapsado) — Colapsado oculta el label y centra el ícono.
PropiedadTipoValores: Con flecha, Sin flecha, Subcategoría, Divisor — "Sin flecha" es igual a Default/Hover/Select pero sin el caret — se usa en ítems sin submenú. Subcategoría indenta el ítem y agrega una marca de selección vertical.
