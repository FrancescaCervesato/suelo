Tooltip

Texto de ayuda contextual que aparece al hacer hover sobre un elemento. Tipo Default para un texto corto, o Compuesto para título, descripción y acción.

Cómo usarlo

Agrega una aclaración breve y contextual sobre un elemento, visible solo al pasar el mouse o enfocar, sin ocupar espacio permanente en la pantalla.

✓ Hacer
  • Usar el tipo Default para una aclaración corta de una línea.
  • Usar el tipo Compuesto cuando necesite título, más de una línea o una acción asociada.
  • Mantener el texto breve — si no entra en dos líneas, es señal de que necesitás otro componente.
✕ Evitar
  • Poner información crítica solo en un tooltip — en mobile o touch no siempre es accesible.
  • Usarlo para una acción que requiere algo más que leer — para eso está el Compuesto con botón, o un Modal.
  • Encadenar tooltips sobre tooltips.
