Modal

Interrumpe el flujo actual para pedir una decisión o mostrar información que no puede posponerse, bloqueando el resto de la pantalla hasta que se resuelva. Conviene reservarlo para decisiones que realmente necesitan ese bloqueo, como confirmar una acción destructiva, y siempre ofrecer una forma clara de cerrarlo sin aplicar cambios. Para avisos simples que no requieren una decisión, un Toast alcanza.

Qué hacer y qué no

Hacer

Usar Warning para acciones que requieren atención del usuario antes de continuar.

Usar Rojo para acciones destructivas e irreversibles, como eliminar datos de forma permanente.

Incluir siempre un botón de cancelar, para que la persona pueda salir sin ejecutar la acción principal.

No hacer

Usar modales para información no crítica — para mensajes simples alcanza un Toast o un banner.

Omitir el ícono de tipo — ayuda a entender de un vistazo si el mensaje es info, warning o error.

Usar textos extensos en el cuerpo — si hace falta más contexto, enlazar a documentación externa.

Propiedades documentadas de este componente

PropiedadTipoValores: Default, Warning, Rojo — 3 variantes en total, definen el ícono, el color del ícono y el botón de acción.
PropiedadTiene ícono / Tiene closeValores: Booleano, Booleano — Muestran u ocultan el ícono de tipo y el botón de cerrar (X) de forma independiente.
PropiedadInput motivoValores: Booleano — Agrega un campo de texto (Label + Placeholder) para justificar la acción antes de confirmarla.
PropiedadTamañoNo aplica — tamaño único de 543px de ancho.
PropiedadEstadoNo definidos como variantes — los estados de interacción se manejan a nivel de los botones internos.
