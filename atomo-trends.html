Trends

Indicador de tendencia positiva, negativa o neutral. Muestra variación porcentual con ícono y color. Usado en dashboards financieros y tablas de datos.

Cómo usarlo

Muestra la variación porcentual de una métrica combinando color e ícono de dirección, para comunicar de un vistazo si algo mejoró, empeoró o se mantuvo estable.

✓ Hacer
  • Combinar siempre el color con un ícono de dirección (↑ ↓) para no depender solo de la percepción de color.
  • Usarlo junto a un KPI o número para dar contexto de evolución.
  • Elegir la variante con fondo cuando necesites más énfasis visual en una card.
✕ Evitar
  • Usar solo el color para indicar la tendencia.
  • Usarlo para valores que no son una variación — ahí un número simple alcanza.
  • Aplicar verde/rojo con un significado distinto al de mejora/empeoramiento en ese contexto.
