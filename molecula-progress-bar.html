Progress Bar

Barra de progreso lineal. Muestra el avance de un proceso de 0 a 100%. El detalle (etiqueta y porcentaje) puede mostrarse u ocultarse por separado.

Cómo usarlo

Comunica cuánto avanzó un proceso con progreso medible (0 a 100%), a diferencia del Spinner que solo indica que algo está en curso.

✓ Hacer
  • Usarla cuando el progreso real se puede calcular (ej. archivos subidos de un total).
  • Mostrar el porcentaje o la etiqueta de detalle cuando ayude a entender cuánto falta.
  • Actualizarla en tiempo real a medida que el proceso avanza.
✕ Evitar
  • Usarla para procesos sin progreso medible — ahí corresponde un Spinner.
  • Dejarla estancada en un valor sin explicación si el proceso se traba o falla.
  • Usarla como elemento decorativo sin relación con un proceso real.
