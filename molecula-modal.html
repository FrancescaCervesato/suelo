Molécula

Modal

Interrumpe el flujo actual para pedir una decisión o mostrar información que no puede posponerse, bloqueando el resto de la pantalla hasta que se resuelva. Conviene reservarlo para decisiones que realmente necesitan ese bloqueo, como confirmar una acción destructiva, y siempre ofrecer una forma clara de cerrarlo sin aplicar cambios. Para avisos simples que no requieren una decisión, un Toast alcanza.

Qué hacer y qué no

Hacer

Reservarlo para decisiones que realmente necesitan bloquear el flujo (confirmar una acción destructiva, por ejemplo).

Ofrecer siempre una forma clara de cerrarlo sin aplicar cambios (Cancelar, tecla Esc, click afuera).

Mantener el contenido breve y centrado en una sola decisión.

No hacer

Usarlo para avisos simples que no requieren acción — para eso alcanza un Toast.

Anidar un modal dentro de otro modal.

Poner formularios largos o con muchos pasos — eso funciona mejor como pantalla completa o Stepper.
