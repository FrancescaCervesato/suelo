Select

Selector desplegable de una opción. Estados: default, abierto, con valor, deshabilitado. Se usa cuando hay 5 o más opciones disponibles.

Cómo usarlo

Permite elegir un único valor de una lista cerrada de opciones, ahorrando espacio frente a mostrarlas todas abiertas.

✓ Hacer
  • Usarlo cuando hay 5 opciones o más, o cuando el espacio disponible es limitado.
  • Ordenar las opciones de forma predecible (alfabético, o por frecuencia de uso).
  • Mostrar un estado vacío claro ("Seleccioná una provincia") cuando no hay valor elegido.
✕ Evitar
  • Usarlo con menos de 5 opciones si podés mostrarlas todas a la vez — un Radio button se escanea más rápido.
  • Precargar una opción como si fuera elegida por la persona cuando en realidad es solo un placeholder.
  • Usarlo para selección múltiple — para eso está el Seleccionador múltiple.
