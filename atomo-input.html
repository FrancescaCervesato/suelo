Input

Error

Qué hacer y qué no

Hacer

Mostrar el error apenas se pueda validar el campo, no recién al enviar todo el formulario.

Explicar en el mensaje de error cómo resolver el problema, no solo que existe.

Usar el estado "no editable" para datos de solo lectura dentro de un formulario editable.

No hacer

Usar el placeholder como reemplazo del label — desaparece apenas la persona empieza a escribir.

Dejar un campo en estado de error sin ningún mensaje que lo acompañe.

Usarlo para elegir entre opciones de una lista cerrada — ahí corresponde un Select.
