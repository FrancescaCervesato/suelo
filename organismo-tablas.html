Organismo

Tablas

Componente para mostrar datos tabulares. La cabecera soporta orden y filtro por columna; las celdas tienen 8 tipos de campo y hasta 4 niveles de indentación para filas jerárquicas.

Cómo usarlo

Organiza datos estructurados en filas y columnas, permitiendo comparar, ordenar, filtrar y actuar sobre múltiples registros a la vez.

✓ Hacer
  • Elegir el tipo de campo (Texto, Número, Link, Chip, Editable) según el dato real que representa cada columna.
  • Usar los niveles de indentación solo cuando los datos tienen una jerarquía real (ej. cartera → instrumento).
  • Fijar la columna de acciones y evitar más de una acción visible por fila — el resto va en un desplegable.
✕ Evitar
  • Usar el tipo Chip para un valor que en realidad es un estado semántico — para eso ya existe el átomo Tag.
  • Usar el tipo Editable sin un indicador claro de que el campo se puede modificar.
  • Usar una tabla para mostrar un solo registro — ahí una Card comunica mejor.
