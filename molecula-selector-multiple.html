Selector múltiple

Barra de acciones masivas que aparece al seleccionar varias filas o tarjetas. Muestra la cantidad de seleccionados y acciones sobre ese grupo (seleccionar todos, habilitar, deshabilitar).

Cómo usarlo

Aparece al seleccionar varias filas o tarjetas a la vez, para aplicar una acción sobre todo el grupo en lugar de repetirla una por una.

✓ Hacer
  • Mostrar siempre la cantidad de elementos seleccionados.
  • Usar el tipo Flotante sobre una grilla de tarjetas, y Grilla cuando se integra dentro de una tabla.
  • Ofrecer "Seleccionar todos" cuando la lista completa sea razonablemente chica.
✕ Evitar
  • Mostrar más de 3-4 acciones en la barra — el resto conviene agruparlo en un menú de opciones.
  • Dejarla visible cuando no hay ningún elemento seleccionado.
  • Usarla para una selección única — ahí no hace falta una barra de acciones masivas.
