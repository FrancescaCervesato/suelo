Barra de acciones masivas que aparece al seleccionar varias filas o tarjetas. Muestra la cantidad de seleccionados y acciones sobre ese grupo (seleccionar todos, habilitar, deshabilitar).

Tip de uso
Usá el tipo Flotante cuando la barra debe superponerse al contenido (ej. sobre una grilla de tarjetas) y el tipo Grilla cuando puede integrarse como una fila más dentro de una tabla.
