Iconos e ilustraciones

Set de iconografía e ilustraciones vectoriales relevado 1:1 de Figma ("Sistema de diseño 1.0" y "Zona de diseño").

Iconografía

Set de íconos de interfaz en 16×16px, con trazos simples y esquinas redondeadas. Se usan en botones, inputs, tablas y navegación para reforzar una acción o un estado sin depender solo del texto.

✓ Hacer
  • Usar el ícono que mejor represente la acción o el estado, nunca uno ambiguo "porque queda bien".
  • Mantener el tamaño 16px en contextos de texto e inputs, para no romper la alineación con la tipografía.
  • Acompañar con texto cuando el ícono comunica una acción destructiva o poco frecuente.
✕ Evitar
  • Mezclar este set con íconos de otra librería o de otro estilo de trazo en la misma pantalla.
  • Usar un ícono como único indicador de un estado crítico (ver Accesibilidad).
  • Escalar el ícono por fuera de los tamaños documentados (16px acá; ilustraciones en 102px o 50px).

Ilustraciones

Biblioteca de ilustraciones vectoriales para empty states, onboarding y comunicación visual, alineada a la paleta del sistema. Cada tipo existe también en una variante de color "Acento" (no incluida en este catálogo) y en tamaño chico (50px) además del grande (102px) que se muestra acá.

✓ Hacer
  • Usar para humanizar la interfaz en estados vacíos (ver molécula Empty state).
  • Preferir ilustración sobre fotografía para mantener consistencia visual.
  • Elegir el tipo que representa literalmente la situación (ej. "404" para error de ruta, "No wifi" para conectividad).
✕ Evitar
  • Mezclar estilos ilustrativos distintos dentro de la misma pantalla.
  • Usar una ilustración sin texto alternativo cuando comunica el estado de la pantalla (ver Accesibilidad).
